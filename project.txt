Aba Divergencias
-------------------------------------------------------
Responsavel por exibir as Divergencias de conferecia de saida que ainda não foram tratadas no 
sistema. Deve possuit um seção com os principais filtros no contexto da conferecia para trazer 
as divergencias em aberto.
Ações:
    - Buscar Divergencias
        Utilizando os filtros preenhidos deve buscar as divergencias em aberto no Sankhya e 
        retornar o resultado da busca como uma lista de registros
    - Limpar Filtros
        Tem como objetivo limpar zerar ou limpar todos os filtros preenhidos pelo usuário.
    - Buscar itens da Divergencia
        Deve buscar os itens referentes a Divergencia selecionada na tabela de Divergencias.
    - Salvar Tratativa da Divergencia
        Deve enviar para o Sankhya os dados referente a tratativa informado pelo usuario na
        tabela de itens da divergencia.
    - Atualizar Divergencias
        Deve buscar os dados atualizados das divergencias.
